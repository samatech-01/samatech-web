# SamaTech web fonts

Official Google Fonts variable WOFF2, normal style, Latin subset (Indonesian text, punctuation and Latin characters). Downloaded 9 November 2026. Files are unmodified and self-hosted; visitors do not contact Google Fonts. The active combination is **Manrope for headings/application names** and **Inter for body/UI**.

| File | Family | CSS weights |
| --- | --- | --- |
| inter-latin-variable.woff2 | Inter | 400–700 |
| manrope-latin-variable.woff2 | Manrope | 600–800 |

The previously supplied Plus Jakarta Sans file and its license are retained as legacy assets; the current stylesheet does not load it.

The families use SIL Open Font License 1.1. Keep the corresponding OFL text files when distributing these font files. The two active preloads in index.html match CSS sources, with font-display: swap and system sans-serif fallbacks. Only Manrope and Inter normal-style Latin font files are loaded; no italics or unrelated language subsets.
